# Paper map

Where each part of the revised paper is found in this repository. Section, figure and table numbers follow the revised
manuscript. Paths are relative to the repository root unless a section names another base directory. The `MAPPING.md`
file of each experiment gives the file of every figure, table and macro value in more detail.
